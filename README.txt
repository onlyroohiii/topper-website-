TOPPERS STARTER WEBSITE

Included:
- index.html: responsive public homepage
- styles.css: layout, colours, mobile styling and dark theme
- script.js: theme toggle, mobile menu and demo enquiry form
- portal.html: Admin, Teacher, Parent and Student login screen previews

HOW TO OPEN:
1. Extract TOPPERS_starter_website.zip.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted TOPPERS folder.
4. Open index.html.
5. If Live Server is installed, right-click index.html and choose Open with Live Server.
6. Otherwise, open index.html directly in your browser.

IMPORTANT:
This is a frontend prototype, not a production student-management system.
Login screens are previews only; no credentials are verified or stored.
The enquiry form opens a draft email and does not send or store information.
No student records, fees, attendance or messages are stored.
Do not enter real student information or passwords.
Before real academy use, secure server-side authentication, a database, access permissions, backups and privacy review are required.
No Supabase is included.
